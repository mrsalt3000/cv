# Evgeniy Babkin — CV

LaTeX source and compiled PDF of my CV. One file per format, no build system to install beyond a TeX distribution.

**Contents**

- `Evgeniy_Babkin_Senior_Data_Analyst.tex` — the source
- `Evgeniy_Babkin_Senior_Data_Analyst.pdf` — the compiled document

**Build**

```bash
make          # or: pdflatex Evgeniy_Babkin_Senior_Data_Analyst.tex
make clean    # remove aux/log/out files
```

Requires `pdflatex` (TeX Live or MacTeX) with `titlesec`, `enumitem`, `tabularx`, `fancyhdr`.

**Layout**

- One page: summary, experience (Raiffeisen Bank, Yandex, INGKA/IKEA), education, skills
